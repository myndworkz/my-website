Project Overview

This spatial analysis identifies high-priority opportunity zones for agroforestry within the UNESCO Dyfi Biosphere Reserve. The model isolates unconstrained agricultural land positioned to serve as ecological corridors between fragmented stands of Ancient Semi-Natural Woodland (ASNW).

Selection Criteria & Methodology

1. Target Vegetation

Filtered for 0.25 ≤ NDVI ≤ 0.50 using Sentinel-2 imagery to capture open pasture and degraded grassland while excluding existing dense canopies and bare ground.

2. Workable Topography

Targeted 2° ≤ Slope ≤ 15° using OS Terrain 50 data to isolate accessible terrain while excluding waterlogged valley bottoms (< 2°) and hazardous slopes (> 15°).

3. Riparian Protection

Applied a 20-meter exclusion buffer along all primary watercourses to safeguard aquatic ecosystems and prevent runoff during ground preparation.

4. Woodland Connectivity

Prioritized parcels within a 500-meter buffer of Ancient Woodland Inventory (AWI) sites to maximize seed dispersal and structural habitat connectivity.
